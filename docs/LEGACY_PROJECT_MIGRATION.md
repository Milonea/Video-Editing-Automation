# 기존 프로젝트 이전 안내

이 문서는 기존 로컬 영상 프로젝트와 자동화 설정을 새 프레임워크로 옮길 때 데이터를 보존하기 위한 절차입니다. 현재 자동 변환기는 없으므로 원본 프로젝트를 변환하지 않습니다.

1. 원본 코드 저장소와 미디어 Workspace를 별도로 백업합니다.
2. Git history는 대상 저장소로 복사하지 않습니다. 필요한 기능과 파일을 Migration Matrix에서 분류합니다.
3. 사용자 Persona, 개인 기록, 실제 미디어, 토큰, 로컬 절대경로와 장치 정보는 공개 저장소에서 분리합니다.
4. 원본 project manifest와 media 목록을 읽기 전용으로 내보내고, 상대경로·자산 ID·Workspace ID를 새 계약에 매핑합니다. 기존 Workspace manifest는 새 `.vea-workspace.json` 이름으로 복사하고 ID·상대경로를 검사합니다.
5. 변환된 manifest를 새 위치에 생성하고 원본 데이터와 파일 hash를 대조합니다. 원본은 검증 후에도 삭제하지 않습니다.
6. 시퀀스, 컷, 전사, 자막과 체크포인트가 일치할 때만 편집기 adapter 검증을 진행합니다.
7. 중단·누락·충돌은 차단 상태로 남기고, 성공으로 처리하지 않습니다.

현재 Workspace Resolver와 `vea` CLI는 이전되었습니다. VESupport의 기존 seconds 기반 Recipe 입력을 공통 정수 프레임 계약으로 바꾸는 자동 변환과 Premiere 프로젝트 변환은 아직 구현되지 않았습니다.
